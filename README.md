# BikeRider – WebGL test sürümü

Bu repo yalnızca oyunun derlenmiş **WebGL test sürümünü** içerir (kaynak proje burada değildir).

**Oyna:** https://kayasibel.github.io/BikeRider/

## Kontroller
- **Telefon:** Ekranın sol/sağ yarısına basılı tut = yön · sağ alttaki düğme = sprint · sol alttaki düğme = fren
- **Klavye:** A/D yön · W sprint · S fren · C kamera · Esc duraklat · F1 FPS

## Notlar
- Oyun dikey ekran için tasarlandı; telefonda en iyi deneyim için telefonu dik tutun.
- Test sürümünde gölgeler kapalı (bazı tarayıcılarda WebGL gölge uyumsuzluğu var).
- İlk açılışta ~25 MB indirilir; diğer bisiklet modelleri garajda seçilince iner (0,2-0,4 MB); sonraki açılışlarda tarayıcı önbelleği kullanılır.
